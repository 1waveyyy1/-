Это CRM система для управления курьерами службы доставки.
Программа предназначена для диспетчера, который отслеживает занятость курьеров и может назначить курьеру заказ.
При создании заказа используя графический интерфейс на карте выбирается адрес, курьер и указывается товар для доставки(вместе с количеством).
Курьер получает письмо на указанную в базе данных электронную почту со всей информацией и ссылкой на адрес.
